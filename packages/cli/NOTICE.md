# bambiui distribution scope

The bambiui CLI, its compiled shared runtime, and provided component sources/integration templates are MIT licensed. Retain LICENSE and its copyright/permission notice when redistributing substantial portions.

The private Studio application is not included in this npm package and is not open-sourced by the CLI license. In the source repository, shared files are licensed individually through distribution-license.json; other Studio files remain outside that grant.

User-authored designs, System JSON, token values, project data and content are not assigned a license by bambiui. Software copyright permission does not grant trademark rights in the bambiui name or logos.

Third-party packages and fonts keep their own licenses. React and Base UI are host dependencies, not implementations bundled into this CLI. Optional Google Fonts presets load remote styles/fonts and remain subject to the selected font's license and network/privacy conditions. Font files are not distributed in the npm package.
